# template-python

Pythonプロジェクトのテンプレートリポジトリ

## 概要

モダンなPython開発のベストプラクティスを組み込んだテンプレートです

## 主な機能

- uv - 高速なパッケージマネージャー
- Ruff - 高速なリンター・フォーマッター
- pre-commit - コミット前の自動チェック（mainブランチ保護含む）
- devcontainer - VSCode開発コンテナ対応（認証情報の永続化対応）
- Claude Code設定 - AI支援開発の設定済み（セキュアな権限管理）
